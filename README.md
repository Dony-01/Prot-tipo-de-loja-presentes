Desenvolvi um site simples e moderno para funcionar como catálogo digital da loja, permitindo que os clientes visualizem os produtos de forma organizada, com fotos, descrição e preço.

A ideia é facilitar para que os clientes encontrem rapidamente o que procuram e possam montar um carrinho com os produtos desejados. Ao finalizar, o site envia automaticamente uma mensagem para o WhatsApp da loja com os itens selecionados, tornando o atendimento mais rápido e prático.

O site pode funcionar inicialmente como um catálogo online gratuito, hospedado na internet, permitindo que a loja compartilhe o link nas redes sociais e com clientes.

No futuro, caso a empresa deseje, o projeto também pode evoluir para uma loja virtual completa, com domínio próprio, painel de produtos e até integração com pagamentos online.

O objetivo é começar com uma solução simples, funcional e sem custo inicial, mas que também permita crescer junto com a empresa.
